Region view

Caveat - region and product effects overlap. In this dataset each product is sold in exactly 1 region (max regions per product = 1), and each region carries only 2 of the 8 products. A region's result is therefore its two products' result, and a product's result is its region's. The two views are confounded: do not read a regional difference as a regional effect, or a product difference as a product effect. The data cannot separate them.

How to refresh (manual)

pip install pandas numpy openpyxl
python src/build_dashboard.py --input data/source/Nova_CFO_MIS_Complete_Synthetic_Dataset.xlsx --out outputs/v2
python tests/test_dashboard.py          # reconciliation checks

To use a newer synthetic extract: place it under data/, first build and review the v1 MIS candidate with python run_mis.py run (human approval remains separate), then rerun the commands above on that file. See docs/DASHBOARD_V2.md.
